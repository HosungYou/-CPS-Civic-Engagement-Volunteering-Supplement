## A. LPA (잠재 프로파일 분석) 관련 정의

### A-1. LPA 지표 구성 — ✅ 최종 확정: **5개 지표 (VLVOLFQ 제외, CEPOLCONV 추가)**

| 번호 | 지표 | 변수 | 조작적 정의 | 유형 |
|------|------|------|-------------|------|
| 1 | 정치 참여: 불매운동 | CEBOYCOTT | 이진 (2=예→1, 1=아니오→0) | 이진 |
| 2 | 정치 참여: 공직자 연락 | CEPUBOFF | 이진 (2=예→1, 1=아니오→0) | 이진 |
| 3 | 정치 대화 빈도 | CEPOLCONV | 역코딩 (7-원래값), 1=전혀~6=매일 | 연속 |
| 4 | 사회적 상호작용 | (CESOCCONTCT+CESOCIALIZE)/2 | 역코딩 후 평균, 1=전혀~6=매일 | 연속 |
| 5 | 조직 가입 수 | VLMEMBERN | 가입 조직 수 (연속형) | 연속 |

**자원봉사 빈도(VLVOLFQ)를 기본 모델에서 제외한 이유:**
- Phase 2a에서 자원봉사 참여를 종속변수로 예측 → LPA 지표에 자원봉사 정보가 포함되면 순환성(circularity) 발생
- 리뷰어가 "프로파일이 이미 자원봉사 정보를 내포하므로 예측력이 높은 것은 자명하다"고 비판할 위험
- **VLVOLFQ 포함 6개 지표 모델은 강건성 검증(F-1)으로 실행**

**CEPOLCONV 추가 근거:**
- 데이터 검증에서 CEPOLCONV가 6점 빈도 척도(유효 응답률 99.1%)임이 확인됨
- VLVOLFQ 제외 시 빈 자리를 채우면서, "정치적 대화"라는 고유한 시민참여 차원 포착
- 최종 5개 지표 = 정치적(3) + 사회적(1) + 조직적(1) → 시민참여의 다차원성 포괄

**LPA 투입 전 표준화:** 모든 지표를 z-score로 표준화 (평균=0, 표준편차=1)

### A-2. 정치 참여 지표 처리 — 결정: **C안 (개별 이진 변수)**

- CEBOYCOTT → 이진 (2→1, 1→0)
- CEPUBOFF → 이진 (2→1, 1→0)
- 합산 지표를 만들지 않음 (각각 LPA에 독립적으로 투입)

**근거:** 불매운동 = 소비자적/비공식적 정치행동, 공직자 연락 = 제도적/공식적 정치행동. 합산하면 질적 차이 소실.

### A-3. 사회적 상호작용 측정 — ✅ 최종 확정: **역코딩 평균값**

- 원래 척도: 1=매일(Basically every day) ~ 6=전혀(Not at all)
- **역코딩:** `사회적_상호작용 = (7-CESOCCONTCT + 7-CESOCIALIZE) / 2`
- 결과값 범위: 1.0(전혀) ~ 6.0(매일)
- **높은 값 = 높은 사회적 상호작용**

**역코딩 근거:** CEBOYCOTT(1=참여), CEPUBOFF(1=참여), VLMEMBERN(높을수록 많은 가입) 모두 "높은 값 = 높은 참여"이므로, 빈도 척도도 동일 방향으로 통일. LPA 프로파일 해석 시 직관성 확보.

**CEPOLCONV도 동일하게 역코딩:** `정치대화 = 7 - CEPOLCONV` (1=전혀 ~ 6=매일)

### A-4. 프로파일 수 결정 — 결정: **A안 (데이터 기반)**

- BIC + Entropy + BLRT 종합 판단
- BIC 엘보우 지점 + Entropy ≥ 0.70 + BLRT p < .05
- 1~7개 프로파일 비교 후 최적 모델 선택

### A-5. 프로파일 할당 기준 — 결정: **사후확률 ≥ 0.70**

- 사후확률 0.70 미만 제외
- 민감도 검증: 0.60, 0.70(기본), 0.80

## C. Phase 2b — 경계선(Threshold) 분석

### C-1. '이탈' 정의 — ✅ 수정 확정: **공식 활동 수 = 0**

> **⚠️ 데이터 검증 결과:** 6개 활동(빈도 척도 포함) 기준으로 "완전 이탈"은 N=43(0.8%)에 불과하여 분석 불가. 빈도 척도(정치대화, 사회적교류)는 거의 모든 성인이 월 1회 이상 수행하므로 이탈 기준에 포함하면 "이탈자"가 거의 사라짐.

**수정된 이탈 판정: 4개 공식(formal) 시민참여 활동 기준**

| 번호 | 활동 | 변수 | "참여" 기준 | 유형 |
|------|------|------|------------|------|
| 1 | 자원봉사 | VLSTATUS | = 2 | 공식적/조직적 |
| 2 | 기부 | VLDONATE | = 2 | 공식적/자선적 |
| 3 | 불매운동 | CEBOYCOTT | = 2 | 소비자적/정치적 |
| 4 | 공직자 연락 | CEPUBOFF | = 2 | 제도적/정치적 |

- **이탈(Disengaged):** 4개 중 0개 참여 → N=233 (4.3%)
- **참여(Any Engagement):** 4개 중 1개 이상 → N=5,245 (95.7%)

**공식 활동만 사용하는 이론적 근거:**
- Verba et al.(1995): 시민적 자원주의 모델에서 시민참여의 핵심 행위는 시간, 돈, 기술의 자발적 투입을 수반하는 공식적 행위
- 사회적 교류(CESOCCONTCT/CESOCIALIZE)와 정치 대화(CEPOLCONV)는 "비공식적 사회 생활"로, 의도적 시민참여와 구별됨 (Zukin et al., 2006)
- 공식/비공식 구분은 Phase 2b의 정책적 함의를 명확히 함: "어떤 사람이 어떤 공식적 시민참여도 하지 않는가?"

**활동 수 분포 (4개 공식 활동):**
- 0개: N=233 (4.3%) — 이탈
- 1개: N=2,576 (47.0%) — 단일 참여
- 2개: N=1,962 (35.8%) — 다중 참여
- 3개: N=603 (11.0%) — 적극 참여
- 4개: N=104 (1.9%) — 완전 참여

**추가 분석 옵션:** 활동 수(0-4)를 연속형 종속변수로 사용하는 보조 분석 실행 → 이진 분석의 보완

### C-3. LPA 프로파일과의 연결 — ✅ 최종 확정: **두 모델 비교**

- **Model A (인구학 모델):** 인구학적 예측변수만 투입 (프로파일 미포함)
- **Model B (프로파일 통합 모델):** 인구학적 예측변수 + LPA 프로파일 더미
- 두 모델의 SHAP 결과 비교: Model A에서 인구학적 요인의 순수 효과 확인, Model B에서 프로파일의 추가 설명력 확인

**근거:** 프로파일이 시민참여 지표로 구성되어 있으므로, 이탈(시민참여 없음) 예측에서 프로파일이 다른 변수를 압도할 위험. 두 모델 비교를 통해 인구학적 요인의 독립적 역할을 보존.

## G. PA 선택의 정당화

본 연구가 전국 데이터 대신 PA에 집중하는 이유:

1. **지리적 다양성:** Philadelphia(대도시) ~ Appalachia(농촌) ~ Pittsburgh(중규모 도시)를 아우르는 지리적 스펙트럼
2. **Rural-Urban 격차:** 동일 주 내에서 도시-교외-농촌의 시민참여 패턴 차이를 통제된 정책 환경 내에서 비교 가능
3. **Extension 전통:** Penn State Extension의 역사적 시민참여 프로그램이 존재 → 연구 결과의 실천적 함의 직결
4. **경제적 이질성:** 에너지 산업(서부 PA), 농업(중부 PA), 서비스/기술(동부 PA)의 상이한 경제 구조
5. **인구학적 전환:** 농촌 고령화, 도시 젠트리피케이션, 교외화 진행 — 전국적 추세의 축소판
6. **표본 규모:** N=5,478은 LPA(3-5 프로파일) + GBM/SHAP에 충분

**한계:** 단일 주 분석이므로 외적 타당도(generalizability) 제한. 논문 Discussion에서 명시적으로 기술하고, 향후 연구로 다주(multi-state) 비교 분석 제안.
